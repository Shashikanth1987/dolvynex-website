# DOLVYNEX one-page website

## Preview locally
Open `index.html` in a modern browser. Internet access is needed for the optional Google Fonts; system sans-serif fallbacks are included.

## Publish
Upload the contents of this folder (not the containing folder itself) to your chosen static hosting provider. Then point `dolvynex.com` DNS to that provider using the exact records they supply. Do not guess A/CNAME records; use the hosting provider's current instructions.

## Before public launch
- Replace the placeholder `hello@dolvynex.com` with an active inbox or forwarding address.
- Confirm legal entity and trademark status before adding legal claims or ®.
- Review copy and disclaimer with appropriate professional advice.
- Add privacy policy/contact details if collecting personal data.
- Add analytics/cookies only with appropriate consent and disclosures.
- Test mobile, desktop, accessibility and all links.
